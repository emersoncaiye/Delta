# Aesthetic Framework

Every object in Delta must pass four questions.

## 1. Is it quiet?

Not loud. Not performative. No big logos. No screaming for attention. It's beautiful, but it doesn't need to prove it.

## 2. Is it smart?

Not cheap. Smart. The price reflects the value. It's a find — something underappreciated or fairly priced.

## 3. Is it worth circulating?

Not disposable. Not fast consumption. It can be cleaned, repaired, loved by multiple people. It gets better with age, not worse.

## 4. Is it usable?

Not a collector's item. Not a shelf decoration. Something you actually use in daily life. A cup, a lamp, a scarf, a small bag.

## In One Sentence

Quiet, smart, worth circulating, usable.

## Vibe Reference

Think: calm mornings, first apartments, lived-in warmth, soft luxury without the price tag.
