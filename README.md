# Delta / 三角洲计划

**Objects for a moving life.**

Delta is a curated circular space for people who move often — between cities, countries, life stages — but still want to live with beauty.

We select objects that are quiet, intelligent, worth circulating, and genuinely usable. You can take them home, use them for a while, and when you no longer need them — because you're moving, or just ready for something new — you can send them back.

Not a secondhand store. A circular space with a point of view.

---

**One-line:** A circular space curated by one person's aesthetic.

**Core belief:** Beautiful things should circulate. Because no one needs to hoard.

**Why Delta:** A river delta is where water flows, splits, merges, and finds new paths. Things circulate. Nothing stays. Everything moves.
